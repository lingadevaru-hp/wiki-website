# Thoshan's Wiki

A personal editorial knowledge base built with modern web technologies.

## Overview

Thoshan's Wiki is a full-stack application featuring:

- **React SPA** with client-side routing
- **Cloudflare Workers** backend and static asset delivery
- **Cloudflare D1** for production newsletter data; PostgreSQL/Drizzle remains
  for the legacy API and backfill path
- **Article TTS** with speech synthesis
- **HonKit documentation** for developer guides
