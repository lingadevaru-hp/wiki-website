# Quick Start

Get the development servers running in under 5 minutes.

## Start Development

```bash
# Start all services
pnpm dev
```

This runs:
- **Frontend** (Vite) on `http://localhost:5173`
- **API Server** on `http://localhost:3000`
- **Mockup Sandbox** on `http://localhost:5174`

## Open the App

Navigate to `http://localhost:5173/wiki/home` to see the wiki.

## Useful Commands

| Command | Description |
|---------|-------------|
| `pnpm dev` | Start all dev servers |
| `pnpm build` | Typecheck + build all packages |
| `pnpm run typecheck` | Typecheck only |
