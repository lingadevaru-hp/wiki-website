# Adding Articles

## Steps

1. Create a new directory under `public/articles/<slug>/`
2. Add `index.json` with metadata
3. Add `content.html` with the article body
4. Add any assets to `assets/`
5. Update `public/articles/index.json` with the new entry

## Category Colors

Categories are defined in `src/lib/categories.ts`. Each category has a display name and color.
